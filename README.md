# 🤖 AI Document Analyzer API

Асинхронный микросервис для обработки и анализа документов. Проект демонстрирует современные подходы к бэкенд-разработке с использованием асинхронного стека.

## 🛠 Технологии и стек
* **Python 3.11+**
* **FastAPI** (высокопроизводительный асинхронный веб-фреймворк)
* **SQLAlchemy 2.0 (AsyncIO)** + **asyncpg** (асинхронная работа с реляционной БД)
* **PostgreSQL** (реляционная база данных)
* **Docker & Docker Compose** (контейнеризация и оркестрация сервисов)
* **Uvicorn** (ASGI-сервер)

## 🏗 Архитектура и ключевые особенности
1. **Неблокирующий I/O:** Использование драйвера `asyncpg` и асинхронных сессий SQLAlchemy позволяет обрабатывать множество одновременных запросов без блокировки Event Loop.
2. **Фоновые задачи (Background Tasks):** Тяжелые процессы (симуляция анализа текста/ИИ) вынесены в неблокирующие фоновые задачи через `asyncio.create_task()`, что позволяет мгновенно отвечать клиенту (паттерн Request-Acknowledgment).
3. **Контейнеризация:** Полная изоляция веб-приложения и базы данных в Docker-контейнерах с настроенным сетевым взаимодействием и автоматическим созданием таблиц при старте.
